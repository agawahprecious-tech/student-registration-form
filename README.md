# Student Registration System

## Project Description
This is a web-based Student Registration System
developed using HTML, CSS, PHP and MySQL.

## Requirements
- XAMPP
- PHP
- MySQL
- Web browser
- Visual Studio Code

## Installation Steps

1. Copy the student_registration folder.
2. Paste it inside the XAMPP htdocs folder.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import database/database.sql.
6. Open your browser.
7. Enter http://localhost/student_registration/

## Main Features

- Student registration form.
- Full name validation.
- Email validation.
- Phone number validation.
- Matriculation number validation.
- Date of birth validation.
- Department and level selection.
- Gender selection.
- Password confirmation.
- Database storage.

## Database

Database name: student_registration

Table name: students

## Security

- Server-side validation using PHP.
- Password hashing.
- Prepared SQL statements.
- Unique email addresses.
- Unique matriculation numbers.
